# Kalendarz opon

Prosty kalendarz wymiany opon dla warsztatu: widoki Dziś / Tydzień / Miesiąc, dodawanie wizyt,
przechowalnia opon, blokowanie dni, wydruk dnia (A4), kopia do Excela i statystyki (na hasło).

## Pliki

- `index.html` – strona
- `style.css` – wygląd
- `app.js` – działanie kalendarza
- `store.js` – zapis danych (teraz w przeglądarce; docelowo Firebase)
- `serve.ps1` – lokalny podgląd: `powershell -File serve.ps1` → http://localhost:8770
